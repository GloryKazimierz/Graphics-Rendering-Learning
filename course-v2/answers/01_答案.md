# 第 01 章答案｜GPU 渲染管线

1. **Vertex Shader（顶点着色器）**主要处理顶点数据，最核心工作之一是把顶点变换到后续 GPU 能用于光栅化的空间。
2. **Fragment Shader（片元着色器）**主要计算每个 fragment 的输出，例如颜色、Normal、Light Data 等。
3. **Rasterization（光栅化）**负责判断三角形覆盖了哪些屏幕采样位置，并产生 fragments。
4. 三角形最常用，是因为三个点一定定义一个平面，且硬件对 triangle pipeline 高度优化。
5. Fragment 是候选像素结果，还可能被 Depth Test、Blending 等阶段影响；Pixel 是最终写入/显示的结果。
6. 错。`deferred.fsh` 不是负责顶点投影的。
7. 对。Shadow Pass 本质上就是为了阴影目的，从光源视角再渲染/记录一次场景深度。
8. 一般情况下对。一个大三角形可能只有 3 个 vertex，但覆盖成千上万个 fragments。
9. `shadow.fsh` 属于 **Shadow Pass（阴影阶段）**。
10. `final.fsh` 更适合放 **Exposure（曝光）** 之类的后处理，而不是 Vertex Transform。
